# 카카오맵 실측 비교 (2026-11-22 일요일)

- 방법: 카카오맵 웹 길찾기에 출발·도착 좌표를 넣고(같은 링크로 매번 같은 점), 카카오 1위 경로와 "○분"을 기록. 같은 분의 실제 버스 도착 기록(수집기)으로 그 길을 재생해 실제 도착을 맞댐.
- 시간: 09:00~10:50, 12:00~13:30, 10분마다. 수집이 10:50·13:50에 끝나 그 뒤 도착은 '기록 끝 이후'로 표시하고 요약에서 뺌.
- 구간: 강남역→신사역, 삼성역 7번 출구→청담역·경기고교, 흑석역→성수사거리, 그리고 실제 장소 쌍(카카오 1위가 수집한 6개 버스 또는 모델에 있는 지하철만 쓰는 쌍).
- 요약에서 뺀 것: 카카오 1위와 같은 길이 앱 후보에 없던 행(비고 칸 표시), 수인분당선 한티역을 쓰는 쌍(역이 모델에 없음).

## 결과 (유효 45회)
- 카카오 1위 길을 그대로 탔을 때 카카오가 말한 도착보다: 평균 2.1분 늦음, 2분 이상 늦은 회수 22회.
- 가장 크게 늦은 예: 09:22 신사근린공원→은마치안센터(카카오 "143번 10:07" → 실제 10:17), 09:01·12:40 흑석역→성수사거리(카카오 "9호선→146번" → 실제 10분 늦음), 12:50 신논현 쪽→삼성1파출소(9호선, 12분 늦음).
- 반대로 카카오가 넉넉한 곳도 있음: 삼성역→청담역은 카카오 14분, 실제 8~9분.
- 이 앱 추천은 카카오가 말한 도착보다 평균 4.5분 빠름. 대부분 따릉이를 넣은 길이고, 지하철만 쓰는 쌍에서는 이 앱이 걷기·기다림을 더 길게 잡아 카카오 약속보다 늦게 나온 경우도 있음(예: Q020 -7분).
- 해석 주의: 지하철 구간의 늦음은 주로 걷는 시간과 승강장까지 거리 차이에서 나온다(놓치기 쉬운 환승 때문이 아님). 버스 구간의 늦음이 이 앱이 겨냥하는 것.
