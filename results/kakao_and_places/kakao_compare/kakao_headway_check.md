# 카카오맵(웹) 길찾기는 배차 간격·기다리는 시간을 넣는가 (2026-11-22 확인)

방법: 카카오맵 웹 대중교통 길찾기의 "상세보기"를 열어, 총 소요 시간과 구간별 시간(걷기·승차)을 비교.

| 구간 | 카카오 총 시간 | 상세 구간 | 구간 합 |
|---|---|---|---|
| 신사근린공원 → 은마치안센터 (143번) | 45분 | 걷기 8분 + 143번 34분 + 걷기 3분 | 45분 |
| 신사근린공원 → 은마치안센터 (3호선 → 143번 등, 환승 1회) | 43분 | 걷기 15분 + 3호선 20분 + 걷기 7분 + 버스 1분 + 걷기 1분 | 44분 |
| 역삼개나리공원 → 싸리재공원 (360번) | 25분 | 걷기 8분 + 360번 12분 + 걷기 6분 | 26분 |
| 강남역 → 신사역 (버스 여러 노선) | 17분 | 걷기 5분 + 버스 7분 + 걷기 5분 | 17분 |

- 총 시간 = 걷기 + 차 안 시간. 정류장에서 버스를 기다리는 시간, 환승할 때 기다리는 시간, 지하철을 기다리는 시간은 0분으로 들어가 있다(1분 차이는 반올림).
- 같은 출발·도착을 09:00~13:30에 10분마다 찾았을 때 총 시간이 한 번도 바뀌지 않았다(kakao_log.csv). 그 시각에 버스가 언제 오는지, 배차 간격이 얼마인지는 총 시간에 반영되지 않는다.
- 경로 결과에는 "이 차를 놓치면 다음 차는 몇 분 뒤"가 없다.
- 확인 범위: 카카오맵 웹. 휴대폰 앱은 확인하지 않았다(앱은 정류장 실시간 도착을 더 보여 줄 수 있음).
